# Student Record & Grading System

## About the Project
The Student Record & Grading System is a simple console-based application developed using Core Java.

It helps users enter student details, calculate total marks, find percentages, and assign grades.

## Technologies Used
- Java
- Core Java
- Scanner Class
- Conditional Statements

## Features
- Enter student name and roll number.
- Accept marks in three subjects.
- Calculate total marks.
- Calculate percentage.
- Assign grades automatically.
- Display student report.

## Sample Output

```text
Enter Student Name: Sana
Enter Roll Number: 101
Enter marks in 3 subjects: 85 90 80

--- Student Report ---
Name: Sana
Roll Number: 101
Total Marks: 255
Percentage: 85.0%
Grade: A
```

## How to Run

1. Install Java JDK.
2. Open the project in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
javac StudentRecord.java
```

5. Run the program:

```bash
java StudentRecord
```
